Smart Security: one app for lighting, curtains, locks and alarms

A smart-home platform that brings lighting, curtains, door locks and security alarm controls into one application, designed to make monitoring and managing many devices simple and intuitive.

Role
UI/UX designer
Users
Smart-home users
Platform
Tablet and mobile
Tools
Figma, Photoshop, Illustrator, After Effects, Lottie

At a glance

Problem

Managing several smart-home devices needed to feel simple, from one place.

My role

I designed the UI/UX concept, the control interface, wireframes, prototypes, reusable components and Lottie motion.

Delivered

The application UI/UX, interactive prototypes, Lottie animations, marketing videos and implementation-ready design files.

What I did

  • Designed the UI/UX concept for a unified smart-home experience from product requirements.
  • Designed the interface for controlling lighting, curtains, locks and security alarm systems.
  • Defined layouts, navigation, information hierarchy and interaction patterns in Figma.
  • Created wireframes and interactive prototypes to validate the workflow.
  • Designed and implemented Lottie animations for UI elements and system feedback, delivered as JSON.
  • Created marketing videos and visual assets, and reusable components for consistency.
  • Collaborated with developers and iterated on technical constraints and implementation feedback.
