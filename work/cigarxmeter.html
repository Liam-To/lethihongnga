CigarXmeter: a luxury cigar discovery platform

A platform that combines expert reviews, community insights, tasting profiles and data-driven ratings, designed around premium visual storytelling and clear data presentation across web and mobile.

Role
UI/UX designer
Users
Cigar enthusiasts, collectors, aficionados
Platform
Web and mobile
Tools
Figma, Photoshop, Illustrator, After Effects, AI-assisted 3D rendering and visual generation

At a glance

Problem

Make cigar discovery and evaluation easier while keeping a premium brand experience.

My role

I designed the brand, the responsive website and the mobile app, including filtering, ratings and a scanner flow.

Delivered

The CigarXmeter logo, responsive website, mobile app UI/UX, interactive prototypes, UI components and AI-assisted visual assets.

What I did

  • Designed the logo and visual identity for a premium, sophisticated brand direction.
  • Designed the responsive website: information architecture, navigation, discovery, cigar details, rating and recommendation flows.
  • Designed the mobile app for discovery and tracking across devices.
  • Designed key features: Cigar Finder, Explorer, cigar details, ratings, reviews, tasting profiles and recommendations.
  • Created wireframes and interactive prototypes for complex discovery, filtering and rating flows.
  • Created 3D cigar visuals, hero banners and backgrounds with AI-assisted visual workflows.
  • Built reusable UI components in Figma for consistency across web and mobile.
